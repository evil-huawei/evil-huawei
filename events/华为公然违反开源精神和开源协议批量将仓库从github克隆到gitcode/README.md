# 华为公然违反开源精神和开源协议将仓库批量克隆到gitcode

# 事件经过
CSDN旗下GitCode大规模作曲Github上的项目到GitCode，但是随后发现这个GitCode是有华为云参与的，而一般来讲，CSDN如果一开始就要这么做他早就这么做了，和华为云合作做出gitcode后为了给gitcode流量选择了违反开源精神的批量抓取，导致github有段时间对国内IP禁用。  
而现在基本上就可以实锤CSDN和华为云在这个事情上是绝对有合作的。
